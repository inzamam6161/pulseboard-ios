# PulseBoard

PulseBoard is a native iOS focus and productivity dashboard built with SwiftUI, SwiftData and Swift Charts.

## Highlights

* Configurable focus timer
* Pause, resume and background recovery
* Persistent SwiftData session history
* Live weekly and monthly analytics
* Searchable and filterable activity
* Light and dark appearance
* Reusable design-system components
* Dynamic Type and VoiceOver-friendly UI

## Architecture

The project uses a feature-based SwiftUI structure with isolated models, persistence services, reusable UI components and analytics logic.

## Technology

* Swift
* SwiftUI
* SwiftData
* Swift Charts
* Structured concurrency
* MVVM-style state separation

## Run

1. Open `PulseBoard.xcodeproj` in Xcode.
2. Select an iPhone simulator.
3. Press `Command + R`.
4. Open Settings and choose **Load Portfolio Sample Data** for demonstration content.

## Status

Portfolio showcase project. No external dependencies.
